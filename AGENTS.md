# Native Formation working instructions

- This `Silica-1283/si_formation` folder is the user-selected canonical source for the game 1.0 native implementation. The former `si_formation_native` folder was renamed here; the old 2.16.2 tree is archived outside this project. Do not substitute archived source based on timestamps.
- Main lifecycle and commander order scope: `Formations.cs`; settings/menu: `ServerSettings.cs` and `FormationMenu.cs`; placement: `Spacing.cs`, `CommanderLineLayout.cs`, `FpsLayouts.cs` and `TerrainProjection.cs`; controllers: `FpsFormations.cs`, `RallyFix.cs`, `Scouting.cs` and `MovementFix.cs`.
- Keep changes focused. Preserve dedicated-server Mono/netstandard2.1 compatibility, native combat/navigation and explicit speed modes, external-order precedence, player-driven exclusions, physical clearance and ownership cleanup unless the user asks to change them.
- The user handles tests and live verification. Do not run or add tests, or start/stop the game/server unless explicitly requested. Documentation-only edits require no build.
- After code changes, build from this folder with `dotnet build Si_Formation.csproj -c Release --ignore-failed-sources`. The default `ServerRoot` is two directories above this project; use the dedicated-server assemblies, never substitute client IL2CPP assemblies. Fix errors caused by the change, rebuild and stop after a successful build. Do not install dependencies or change unrelated settings if blocked.
- Output: `bin/Release/netstandard2.1/Si_Formation.dll`. A successful build does not verify gameplay. Do not install or load another Formation DLL without user authorization.
- Keep runtime identity `Si_Formation.dll` and config `UserData/cfg/Formation/si_formation_native.cfg`, category `Si_Formation_Native`, independent of the source folder name. The native version has no legacy `FormationApi`, blueprint catalogs or personal-setting restoration.
- The project uses recursive default C# inclusion. Keep legacy source, tests and archives outside this project so they cannot enter the native build.
- Read `../../Silica-Shared-Context/AGENTS.md` and its startup/registry instructions, then only relevant shared contracts/dependencies and actual sources. Use retrieval ID `formation`; distinguish current native exports from archived legacy Ranks/editor/optimizer integrations. No cross-repository commits or pushes without explicit authorization.
- After authorized changes, review the diff and API/dependency impact, update verified documentation and refresh affected local index IDs. Finish with the change, build result or reason no build was needed, and only relevant user-owned live checks. Avoid session transcripts.
